# Agentes Especializados do Darknet Prototype

Esta pasta contém agentes especializados para apoiar a evolução do projeto.

## Agentes disponíveis
- game-render-specialist: renderização, câmera, efeitos visuais, performance
- game-engine-architect: arquitetura de motores, modularização e loops de jogo
- game-systems-specialist: combate, loot, progression, crafting e economia
- game-ai-specialist: IA, pathfinding, comportamento de inimigos e companions
- game-open-world-specialist: mundo aberto, mapas grandes, exploração, biomas e eventos dinâmicos
- game-ui-ux-specialist: HUD, menus, inventário, diálogos e usabilidade
- game-network-specialist: multiplayer, WebSocket, UDP, sincronização e lobbies
- game-tools-qa-specialist: automação, testes, QA e validação de builds

## Como usar
Ao pedir para o programador continuar o desenvolvimento, indique qual agente é mais adequado para a tarefa.

Exemplos:
- “Use o agente game-render-specialist para melhorar a iluminação e feedback visual do combate.”
- “Use o agente game-engine-architect para reduzir o acoplamento do fluxo principal.”
- “Use o agente game-systems-specialist para implementar companions e loja.”
- “Use o agente game-ai-specialist para melhorar o comportamento de inimigos e bosses.”
- “Use o agente game-open-world-specialist para melhorar exploração, biomas e conectividade entre zonas.”
- “Use o agente game-ui-ux-specialist para melhorar HUD, inventário e menus.”
- “Use o agente game-network-specialist para integrar multiplayer e sincronização.”
- “Use o agente game-tools-qa-specialist para criar validação de build e testes.”
