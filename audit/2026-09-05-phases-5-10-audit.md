# Audit of Advanced Phases (5-10) — 2026-09-05

## Objective

Validate that campaign phases 6-11 (indices 5-10 in `content/phases.txt`) generate the correct biome, spawn enemies, allow combat, and pass the autonomous bot validation gate.

## Added instrumentation

- Parameter `--start-phase=N` in `src/main.cpp`.
- Static flag `Game::startPhaseOverride` (same pattern as `Game::headless`).
- `Game` reads the override in the constructor to initialize `owPhase`, `currentZone`, `currentRegion`, `owPhaseRadius`, and `owPhaseGoal` from `phaseDef(N)`.

## Found and fixed defect

`Game game;` was created **before** `game.startPhaseOverride = N`, so the constructor always used phase 0 (`LARuins`). The `SCENERY` log showed "Ruins of Los Angeles" even with `--start-phase=5`.

**Fix**: `startPhaseOverride` was made `static` and `Game::startPhaseOverride` is set in `main.cpp` **before** constructing `Game`.

Files changed:

- `src/main.cpp`: parse `--start-phase=N` and static assignment before construction.
- `src/Game.h`: declaration of `static int startPhaseOverride`.
- `src/Game.cpp`: definition and use in constructor.
